<h1 align="center">Audience Analytics</h1>
<p align="center">An audience analysis workspace for exploring activity patterns and reviewing channel-level signals.</p>

<p align="center"><img alt="analytics" src="https://img.shields.io/badge/analytics-172554?style=flat-square"> <img alt="dashboard" src="https://img.shields.io/badge/dashboard-172554?style=flat-square"> <img alt="audience" src="https://img.shields.io/badge/audience-172554?style=flat-square"> <img alt="monitoring" src="https://img.shields.io/badge/monitoring-172554?style=flat-square"></p>

A public showcase of a private project, presenting anonymized interfaces and key workflows. Source code and internal project materials remain private.

## Key workflows

- Look up a channel overview
- Compare activity signals
- Review collection and operational status

## Gallery

Screens are presented individually with their proportions preserved. Identifying branding, contacts and data are replaced with demo content. These previews illustrate the product and do not imply a live service is available.

Some images were anonymized with AI.
